# 未経産牛の乳生産能力の予測
Hackaton 2026 - 未経産牛の乳生産能力の予測

Backend-first application for dairy herd forecasting with async jobs, live progress, and scenario-based Monte Carlo simulation.

## URL
### [DunkanDoika (link)](http://dunkandoika.liveisfpv.ru:8080/)

## Прогнозы
Размещены в директории [Results](./Results/README.md)

# Описание проекта
## Используемый стек

- Backend: FastAPI
- Database: PostgreSQL
- Queue: Redis + RQ
- Object storage: MinIO
- Frontend: Vue 3 + Vite

## Локальный запуск
Предварительно настраиваем [переменные окружения](./docs/Environment.md) в корне проекта.

```bash
cp .env.example .env
docker compose up --build
```

Доступ к проекту осуществляется по следующим портам:
- Frontend: `http://127.0.0.1:5173`
- Backend OpenAPI: `http://127.0.0.1:8081/docs`
- MinIO Console: `http://127.0.0.1:9001`
- Локальная почта SSO (Mailpit): `http://127.0.0.1:8025`

### Локальный вход через SSO

1. Откройте Frontend и зарегистрируйте пользователя.
2. Откройте Mailpit на порту `8025` и выберите письмо подтверждения.
3. Перейдите по ссылке из письма: она подтвердит email и вернет на страницу входа.
4. Войдите с email и паролем, указанными при регистрации.

Для Google/Yandex OAuth необходимо заменить значения `SSO_*_CLIENT_ID` и
`SSO_*_CLIENT_SECRET` в `.env` на реальные ключи провайдеров.

### График и ретроспективная оценка прогноза DIM

График прогноза с интерактивным выбором CSV:

```powershell
python -m pip install -r backend/requirements.txt
python backend/scripts/plot_milk_days_forecast.py
```

Ретроспективная оценка откатывает выбранный срез стада, удаляет будущие события
и сравнивает прогноз с DIM, восстановленным по исходным данным. Это диагностический
когортный backtest: один конечный срез не заменяет полноценный исторический снимок.

```powershell
python backend/scripts/evaluate_milk_days_forecast.py `
  --dataset "herd_sim_project_м5/Data Set 1. Хакатон 26.02.2026.csv" `
  --backtest-months 6 `
  --max-dim-days 350 `
  --mc-runs 100 `
  --show
```

Без `--dataset` файл можно выбрать из списка. В `Results/Backtests` сохраняются
график PNG, помесячное сравнение CSV, метрики JSON и датасет после отката.
Рассчитываются MAE, RMSE, MAPE, смещение и покрытие доверительного интервала.
В CSV сравнения дополнительно записываются фактическое и прогнозное число дойных
животных, а также число исходных записей, для которых сработал предел DIM.

По умолчанию действует единое ограничение `DIM <= 350`. При превышении лимита
стельное животное переводится в сухостой и остаётся в когорте до будущего отёла,
нестельное выводится из активной когорты; числового обрезания DIM нет. Строки,
в которых осеменение произошло уже после такого выхода, помечаются как конфликтные
и исключаются. Значение
можно изменить параметром `--max-dim-days`. Животные со статусом `Перемещена` без
даты перемещения исключаются, поскольку момент их выхода из стада неизвестен.

Скрипт не восстанавливает пропущенную стельность обратным расчётом от будущего
отёла: это было бы утечкой проверочных данных. Животные без восстанавливаемой
предыдущей лактации или первой стельности учитываются в статистике исключений,
а отчёт получает статус `diagnostic`. Для когортного backtest разрешён только
режим `manual` без закупок. Горизонт по одному итоговому снимку ограничен 12 месяцами.

Исходный CSV содержит только последний срез текущей лактации, поэтому оценка
проводится по восстанавливаемой когорте. Для строгой независимой проверки нужны
как минимум два исторических среза одного стада.
